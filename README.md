# 우리 반 모둠 나누기 🎲

선생님과 학생들을 위한 직관적이고 공정한 출석번호 무작위 모둠 편성 웹 애플리케이션입니다.

👉 **웹사이트 바로가기**: [https://creator-yeman.github.io/classroom-group-maker/](https://creator-yeman.github.io/classroom-group-maker/)

---

## ✨ 주요 기능
- 👤 **출석번호 및 결석생 관리**: 출석번호 칩을 원클릭으로 토글하여 결석생 즉시 제외
- 👥 **2가지 편성 방식**:
  - **모둠 개수 기준**: 지정한 개수의 모둠으로 균등 분할
  - **모둠당 인원수 기준**: 모둠당 원하는 인원수 지정 (2명씩 편성 시 홀수 인원은 1인 모둠 없이 3인 모둠으로 자동 흡수)
- 🎲 **두구두구 셔플 애니메이션**: 긴장감 있는 추첨 연출 및 즉시 확인 가능한 **[⏩ 바로 보기]** 기능
- 📋 **결과 클립보드 복사**: 메신저나 문서에 즉시 붙여넣을 수 있는 텍스트 포맷 지원
- 🖥️ **전자칠판 전체화면**: 수업 시간에 몰입감을 높여주는 전체화면 모드
- 💾 **설정 자동 저장**: 학생 수 및 모둠 설정을 브라우저에 저장하여 다음 시간에도 그대로 유지
